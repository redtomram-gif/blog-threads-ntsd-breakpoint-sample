# NTSD and SOS: breakpoint on a specific thread

Two named threads run the same method in a loop. Used as the target process for setting a breakpoint on a method scoped to one specific thread under NTSD/SOS.

Originally published at [NTSD and SOS: breakpoint on a specific thread](https://blogs.msdn.microsoft.com/thottams/2007/03/02/ntsd-and-sos-adding-a-break-point-on-a-method-with-reference-to-a-specific-thread/) on the MSDN `thottams` blog.
